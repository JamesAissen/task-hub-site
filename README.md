# Task Hub

Personal daily brief, task hub, and order tracker. Static pages; all personal data lives in a
private Firebase database behind sign-in. Installable as a phone app (PWA).

- `index.html` — Daily Brief (weather, calendars, inbox, next event + gear, money, priority to-dos)
- `tasks.html` — full Task Hub
- `orders.html` — disc/media order pipeline
